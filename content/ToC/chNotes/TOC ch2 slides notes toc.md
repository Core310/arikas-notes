# Context Free Grammers (CFG)
**Formal Def** :Can be written as 5 tuple like ch1, but in this case it's a 4 tuple varient: $(V,\Sigma,R,S)$
1) V: set of vars
2) $\sum$: terminals (these are empty chars in result string)
3) set of rules, each being some var with string of vars + terminals (contains V and $\sum$)
4) $S \in V$ start variable

*Language of the grammer:*
$$
\{w \in \Sigma^*  | S \to w 
\}
$$

## Language Rules
Collection of substitution rules, aka productions. Denoted by some $G_1$ for example: for # being terminal (sometimes $ is used instead..)
$$
\begin{gather}
A \rightarrow 0A1
\\ 
A \rightarrow B
\\
A \rightarrow \#
\end{gather}
$$
So if we had some G generating str 000#111, so our grammer would be:
$$
L(G_{1})=0^n \# 1^n | n \geq 0
$$
We can abbreviate multiple rules with the `|` symbol, so the original $G_1$ would become 
$$A \rightarrow 0A_{1} \ | B \ |\ \#$$ 
- *yields*: $uAv \Longrightarrow v$
- *Derives*: $u\Longrightarrow^* V$

### Language to Grammer ex: 
Say we hv: $0^n 1^n \cup 1^n 0^n$ then we can generate an $S \to S_{1} | S_{2}$ to denote the union. What if it was $\cap$? Result in \$ as only string shared in both sets! (See slide 14)

#### CFG vs normal Grammer?
Normal grammers were as we knew for FAs in [[TOC ch1 slides notes toc]]. It 
doesn't have memory like CFGs do with the stack. Generally denoted using multiple \to symbols instead of just strictly one. 

A CFG may be *ambiguous*  if its possible to get a different parse tree but same result string. For example $E \to E +E | \ id$ could result in a leftmost derivation (if we unwinded E to ID on the left first) or rightmost (OPA). 

#### R/L-linear grammer + Linear Grammer
> [!NOTE] Regular and linear Grammer
> **regular grammar**  right/left-linear. non regular ex $A\to aBb$
> 
> **linear grammar:** **at most one variable** only one var can appear on the RHS
> 
> A regular grammar is always linear,  but **not all linear grammars are regular**.

> **R/L-linear grammer**
> is **right-linear** if all productions are of the form  
> 
> $$
> \begin{gather}
> A \to xB \\
> A \to x
> \end{gather}
> $$  
> 
> Then left would be:
> 
> $$
> \begin{gather}
> A \to Bx \\
> A \to x
> \end{gather}
> $$

> [!NOTE] Linear but *not* Regular  
> Consider the grammar  
> 
> $$
> \begin{gather}
> S \to A \\
> A \to aB \mid \lambda \\
> B \to Ab
> \end{gather}
> $$  
> This grammar is linear (only one variable per RHS) but it is **not regular**, because variables appear in mixed positions (sometimes left, sometimes right).

## Chomsky Normal Form (CNF)

Simply, it's a CFG that must follow the form:
$$
\begin{gather}
A \to BC
\\
A \to a
\end{gather}
$$ 

Note how it can't hv the start symbol going to the RHS
- Each ONLY rule produces:
    - two non-terminal symbols (Strictly 2!!)
    - single terminal symbol
    - ONE instance of start_symbol $\to \lambda$

So if we needed to convert $A \to BCD$ we would need to create an intermediate rule like $A \to BX, \ X \to CD$

 see also [gfg Convert CFG to CNF](https://www.geeksforgeeks.org/theory-of-computation/converting-context-free-grammar-chomsky-normal-form/)

# Pushdown Automata PDAs 
Similar to NFA but has stack for memory. Can recognize some non-regular langauges. 

## Formal Defition: 
As usual we have a tuple, though its a 6 state tuple this time, 
$$
(Q, \Sigma, \Gamma, \delta, q_0, F)
$$
1. $Q$ set of states  
2. $\Sigma$ —  input alphabet  
3. $\Gamma$ — set of pushdown symbols (which can be pushed and popped from the stack) (isnt this just sigma with $ appended?)
4. $\delta$:  defined as inp,pop-> push
5. $q_0 \in Q$ — start state  
6. $F \subseteq Q$ — accept states

**$\nabla$ below means if read(1) ? pop 0 push \$**

## PDA Construction
Each delta follows inp,pop-> push. For a new state we push our current q, input (if we move to a blank location its $\epsilon$ ), the inp is what we want to throw into the stack and pop is what's replaced. 

Formally, we can think of it as a bunch of if else statements;
- for start, begin in a $\epsilon$, input 


1) Arrow into start state $q_1$ 
2) $q_1$ into next state, usually push a \$, inp + pop = $\lambda$
3) Generate rules

## CFG to PDA (hw qn)

Sadly have to logic out mostly, 
here's a quick example with a language generating $0^n 1^n$ or $1^n 0^n$  
$$
\begin{gather*}
    S_1 \rightarrow 0 S_1 1 | \epsilon
    \\ 
    S_2 \rightarrow 1 S_2 0 | \epsilon
    \\ 
    \text{combining both:}
    \\ \boxed{S \rightarrow S_1 | S_2}
\end{gather*}
$$

> [!NOTE] CFG to PDA
> Consider the context-free grammar $G=(V,\Sigma,R,S)$ with $V=\{S,T\},\ \Sigma=\{a,b,c\}$ and productions  
> 
> $$
> \begin{aligned}
> S &\rightarrow aSc \mid T\\
> T &\rightarrow bTc \mid \varepsilon
> \end{aligned}
> $$
>
> **Description of $L(G)$:**  
> Strings with some number of $a$'s, followed by some number of $b$'s, followed by $c$'s, where the number of $c$'s equals the total number of $a$'s and $b$'s.
>
> **Set notation:**  
> $$
> L(G)=\{\,a^{m}b^{n}c^{m+n}\mid m,n\in\mathbb{N}\,\}
> $$
>
> **Explanation:**  
>S defined as: "prepend some $a$ to the start and append some $c$, and add a S in the middle of them OR skip to T. \
> T is defined as: "prepend some $b$, append some $c$ put T in the middle, OR end the string. \
> $\epsilon$ ends string
