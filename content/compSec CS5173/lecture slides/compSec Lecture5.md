‒ P: The set of questions that can be solved in polynomial time
‒ NP: the set of questions for which an answer can be verified in
polynomial time
‒ Modern Cryptography: Without the key, the adversary must
solve an NP problem, where a solution in P with polynomial
time is “currently believed very hard” to find.

PRINCIPLES FOR CIPHER DESIGN
• Confusion:

‒ Make the relationship between the <plaintext, key> input and the
<ciphertext> output as complex (non-linear) as possible
‒ Confusion is mainly accomplished by substitutions

• Diffusion:

‒ Spread the influence of each input bit across many output bits
‒ Diffusion is mainly accomplished by permutations

12
